# 区块链数据分析

## 学习目标
学习获取、处理和可视化链上数据。

## 数据来源

### 1. RPC 节点
- 公共 RPC（Infura, Alchemy, QuickNode）
- 自建节点

### 2. 索引服务
- The Graph（子图查询）
- Dune Analytics（SQL 查询）
- Etherscan API

### 3. 数据聚合平台
- DefiLlama API
- CoinGecko API

## 学习路径

### 第一阶段：基础数据获取
1. 连接 RPC 节点
2. 获取区块信息
3. 解析交易数据
4. 读取事件日志

### 第二阶段：钱包分析
1. 追踪地址交易历史
2. 计算持仓分布
3. 识别关联地址

### 第三阶段：DeFi 数据
1. 获取 DEX 交易数据
2. 计算 TVL
3. 监控流动性变化

### 第四阶段：可视化
1. 实时数据仪表盘
2. 交易流向图
3. 价格走势图表

## 实践项目
- 钱包追踪器
- Gas 价格监控
- DEX 交易分析面板
