# 区块链开发学习项目

## 项目结构

### 1. defi-app - DeFi 应用开发
学习构建去中心化金融应用：
- 钱包连接（MetaMask, WalletConnect）
- 代币交换界面
- 流动性池交互
- 质押/挖矿界面

### 2. mev-protection - MEV 防护机制
学习保护用户免受 MEV 攻击：
- 私有交易提交（Flashbots Protect）
- 滑点保护策略
- 交易隐私方案
- 防夹子检测

### 3. blockchain-analytics - 区块链数据分析
学习链上数据监控与分析：
- 区块/交易数据获取
- 大户钱包追踪
- Gas 价格分析
- DeFi 协议 TVL 监控

### 4. smart-contract-security - 智能合约安全
学习合约安全审计：
- 常见漏洞类型（重入、溢出等）
- 安全审计工具（Slither, Mythril）
- 安全编码最佳实践
- 漏洞案例分析
